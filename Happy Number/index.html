Happy Number

        happy number itu didefinisikan sebagai:
        angka positif bebas, yang mana dipecah jadi pertambahan lalu pangkat
        ulang terus sampe angka = 1, itu happy. selain 1 itu sad

        contoh
        19 itu berarti 1+9
        nah 1^2 + 9^2 = 82
        terus 8^2+2^2 = 68
        seterusnya sampai hasilnya 1

        return true kalo happy number, false kalo not happy number
